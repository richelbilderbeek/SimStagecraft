# Run

Run SimStagecraft in your browser.
This is the Qt version of SimStagecraft, compiled to WebAssembly.

Click on the game first, so that it receives your key presses.

## How to play

- Pick a level, then click 'Start'
- Use 'View' to see the equipment, 'Connect' to connect cables
  and 'Use' to operate the equipment
- In 'Connect' mode, click two connectors to connect (or disconnect) them
- Drag a machine by its border to move it
